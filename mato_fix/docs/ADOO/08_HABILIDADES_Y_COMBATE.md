# Habilidades únicas y combate

El elenco del proyecto está compuesto por las ocho capitanas de escuadrón de *Mato Seihei no Slave* incluidas en el juego. Cada una posee una habilidad diferente y puede utilizarla una vez por combate.

| Capitana | Escuadrón | Habilidad | Efecto |
|---|---:|---|---|
| Konomi Tatara | 1.º | Beast Power | +35 ATK |
| Bell Tsukiyono | 3.º | Canopus | +25 ATK / +20 DEF |
| Yakumo Ezo | 5.º | Night Storm | +40 ATK |
| Tenka Izumo | 6.º | Ame-no-Mitori | +30 ATK / +15 DEF |
| Kyouka Uzen | 7.º | Slave | +45 ATK |
| Varvara Pilipenko | 8.º | Pantheon | +40 DEF |
| Fubuki Azuma | 9.º | Sunset | Recupera 55 HP |
| Ren Yamashiro | 10.º | All-Encompassing Lord of the Cosmos | +30 ATK / +25 DEF |

El 4.º escuadrón no forma parte del elenco solicitado, por lo que el juego trabaja con ocho capitanas.

## Selección de combate

El jugador puede elegir qué capitana propia ataca y cuál enemiga recibe el ataque. El rival selecciona automáticamente su mejor atacante disponible y prioriza como objetivo a la aliada con menor HP.

Las habilidades se integran al mismo flujo de combate y quedan registradas mediante Observer.
